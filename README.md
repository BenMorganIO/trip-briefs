## Setup

1. Go to repo Settings > Pages
2. Set Source to "Deploy from a branch"
3. Select `main` branch and `/ (root)` folder
4. Save - your site will be live at `https://benmorganio.github.io/trip-briefs/`

## Adding New Briefs

Each trip brief is a self-contained HTML file with tabs for:
- Weather models and forecasts
- Public GPX recordings
- Mobile navigation import instructions
- Route hazards and safety gear
- Route waypoints and info

Generated by [Littlebird](https://littlebird.ai).
